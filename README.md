## 特性

- **写一次，少几次复制粘贴**：填写正文、添加图片，选择知乎、即刻、X、微博、掘金沸点或 B站动态，由应用依次填写到对应创作页。
- **一个普通主窗口**：菜单栏与应用内 `⌘0` 唤起同一窗口；Dock 不显示图标，显式唤起移到当前桌面，重复点击只置前、不收起；红色关闭和黄色最小化均收起到后台，绿色最大化禁用，齿轮进入设置。开始填写后自动隐藏一次，手动恢复后不重复隐藏。正文固定六行，超出后内部滚动；渠道按三列等宽排列。
- **文字按原样交给渠道**：正文使用纯文本，保留空白、换行和 emoji；Markdown 符号作为普通字符，不渲染、不自动改写或追加标签。
- **图片一次准备，多处使用**：支持选择本地图片、粘贴图片及 Finder 图片文件，自动去重，可预览、移除，并拖动到目标图片前排序。
- **遇到异常，保留现场**：单渠道失败不阻止其他渠道。渠道图标可前往对应页面，最终「去查看」打开本次任务工作区；导航失败保留原稿，不展示执行日志或原始技术报错。
- **填好之后，由你决定发布**：回读校验文字与附件后交还浏览器工作区，最终发布由用户操作。无需模型服务或 API Key。
- **在线更新**：默认每天检查，发现新版在标题栏轻提醒；设置内可手动检查或关闭自动检查。点击后才下载，准备好后点击「重启并使用新版」。任务和未处理稿件会阻止重启，渠道配置保留。0.17.0 起随 Release 提供签名更新清单与更新包；更早版本需先手工安装。

## 常见问题

**会自动帮我点发布吗？**

应用会把内容填好，最终发布由你操作。看到「已填好」后，前往 ego Lite 逐一检查，再亲手发布。

**标题、图片一定要填吗？支持 Markdown 吗？**

填写正文并选择渠道即可开始，标题、图片选填。正文是纯文本，支持换行和 emoji，不渲染 Markdown；需要话题文字时，直接写入正文。

**需要模型 Key 吗？**

不需要。安装 [ego Lite](https://lite.ego.app/)，并在浏览器中登录目标平台即可。

**登录失效或图片上传失败后怎么办？**

按提示在浏览器中处理，再到主窗口继续对应渠道。如果提示需要检查，先确认页面中的文字和图片，避免重复填写。停止任务会保留内容，已经填到网页上的内容也会保留。

**内容会一直保存吗？**

投递记录仅在本次应用运行内保留，退出后不保证恢复。全部渠道填好并成功打开浏览器工作区后，上一份内容会进入投递记录，编辑区准备好下一份，保留渠道选择；未完成时保留原内容。

## 使用

1. 启动 Inkpost，在主窗口填写正文，按需添加标题和图片。
2. 选择渠道，点击「开始填写」，查看各渠道进度。
3. 遇到需要登录或人工处理的结果，在原页面处理；主窗口提供渠道恢复操作、执行日志及错误详情。
4. 全部已填好后，点击「已完成，前往发布」，在 ego Lite 中逐一检查并发布。

Inkpost 常驻菜单栏，不显示 Dock 图标；发布主窗口使用普通窗口层级。点击菜单栏在当前桌面唤醒，切换其他应用后正常退到后面，不置顶、不抢焦点，也不因失焦自动隐藏。关闭或最小化主窗口均收起并保留内容，不会退出；`⌘Q` 退出应用。`⌘0` 是应用内快捷键，全局快捷键仍待实现（#37）。打包应用取得通知权限后可发送系统提醒。

同一用户下只运行一个墨驿实例；重复打开或直接运行其他应用副本会唤起已有主窗口，保留内容和任务。已有实例未响应时提示错误，不强制结束它或另开一套任务。

窗口行为的构建与自动测试已通过；原生正文输入、设置隔离及关闭恢复已验证。跨桌面、全屏和多显示器唤起尚待现场验收。

菜单栏显示当前填写的渠道，呼吸圆点表示正在执行；完成后显示「已填好，请确认」，异常时显示待处理渠道。启用系统“减少动态效果”后，圆点保持静止。

完成或异常时，系统通知会汇总已填好和待处理的渠道，并给出简短原因。点击通知可打开对应任务的 ego Lite 工作区，不会清空当前内容；旧工作区不可用时会提示错误。更新前的旧通知不支持工作区跳转，请返回墨驿查看。

### 渠道状态与登录恢复

渠道标签显示填写中、填写成功、需登录与其他问题的状态图标。点击登录或问题图标可前往对应 ego Lite 页面；若其他渠道仍在执行，会等本轮自动操作结束再交还浏览器。登录后点击「我已登录，继续」，只继续待登录渠道，也可跳过等待改为手工处理。

填写全部结束后，Space 完成并交还用户。主按钮显示「已填写，需要你手工发布」或「去查看」；点击并成功打开本次任务 Space 后，编辑器恢复新稿并保留渠道选择。内容仍由用户手工最终发布，导航失败不会清空稿件。

填写结束后若无法打开工作区，可点击错误提示后的「我已处理，忽略」，清空本次内容并开始新稿，保留渠道选择。
