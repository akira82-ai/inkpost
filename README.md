## 特性

- **写一次，少几次复制粘贴**：填写正文、添加图片，选择知乎、即刻、X、微博或掘金沸点，由应用依次填写到对应创作页。
- **一个普通主窗口**：菜单栏、Dock 与 `⌘0` 唤起同一窗口；红色关闭和黄色最小化均收起到后台，绿色最大化禁用，齿轮进入设置。开始填写后自动隐藏一次，手动恢复后不重复隐藏。正文固定六行，超出后内部滚动；渠道按四列等宽排列。
- **文字按原样交给渠道**：正文使用纯文本，保留空白、换行和 emoji；Markdown 符号作为普通字符，不渲染、不自动改写或追加标签。
- **图片一次准备，多处使用**：支持选择本地图片、粘贴图片及 Finder 图片文件，自动去重，可预览、移除和排序。
- **遇到异常，保留现场**：登录、内容冲突或上传异常会显示具体结果；单渠道失败不阻止其他渠道。可恢复的任务沿用原页面和内容快照，结果不明时先交给用户检查。
- **填好之后，由你决定发布**：回读校验文字与附件后交还浏览器工作区，最终发布由用户操作。无需模型服务或 API Key。

## 常见问题

**会自动帮我点发布吗？**

应用会把内容填好，最终发布由你操作。看到「已填好」后，前往 ego Lite 逐一检查，再亲手发布。

**标题、图片一定要填吗？支持 Markdown 吗？**

填写正文并选择渠道即可开始，标题、图片选填。正文是纯文本，支持换行和 emoji，不渲染 Markdown；需要话题文字时，直接写入正文。

**需要模型 Key 吗？**

不需要。安装 [ego Lite](https://lite.ego.app/)，并在浏览器中登录目标平台即可。

**登录失效或图片上传失败后怎么办？**

按提示在浏览器中处理，再到主窗口继续对应渠道。如果提示需要检查，先确认页面中的文字和图片，避免重复填写。停止任务会保留内容，已经填到网页上的内容也会保留。

**内容会一直保存吗？**

投递记录仅在本次应用运行内保留，退出后不保证恢复。全部渠道填好并成功打开浏览器工作区后，上一份内容会进入投递记录，编辑区准备好下一份，保留渠道选择；未完成时保留原内容。

## 使用

1. 启动 Inkpost，在主窗口填写正文，按需添加标题和图片。
2. 选择渠道，点击「开始填写」，查看各渠道进度。
3. 遇到需要登录或人工处理的结果，在原页面处理；主窗口提供渠道恢复操作、执行日志及错误详情。
4. 全部已填好后，点击「已完成，前往发布」，在 ego Lite 中逐一检查并发布。

Inkpost 是显示 Dock 和应用菜单的前台应用，菜单栏是快捷入口。关闭或最小化主窗口均收起到后台，不会退出，可从应用菜单或按 `⌘Q` 退出。打包应用取得通知权限后可发送系统提醒。

菜单栏显示当前填写的渠道，呼吸圆点表示正在执行；完成后显示「已填好，请确认」，异常时显示待处理渠道。启用系统“减少动态效果”后，圆点保持静止。

完成或异常时，系统通知会汇总已填好和待处理的渠道，并给出简短原因。点击通知可打开对应任务的 ego Lite 工作区，不会清空当前内容；旧工作区不可用时会提示错误。更新前的旧通知不支持工作区跳转，请返回墨驿查看。
