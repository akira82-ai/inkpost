02 / REQUIREMENTS & STATES

只暂停登录，只保留两个终点。

等待登录是中间状态。任务结束后，主界面只说明结果，再把用户带到本次任务 Space。

01 / IN PROGRESS

一个渠道暂停，其他照常填写

仅确认未登录时暂停该渠道。渠道标签显示填写中、填写成功、需登录、其他问题四种图标。点击登录图标前往对应页面，下方大黑主按钮统一为「我已登录，继续」。已登录的继续，未登录的仍保留。普通超时不冒充未登录。

02 / FINISHED

结束自动操作，立即交还

全部渠道均已结束后，Space 标为「已完成」并交还控制权。它表示填写流程结束，不代表内容已经发布。

03 / NEXT DRAFT

前往成功，再准备下一条

点击「已填写，需要你手工发布」或「去查看」，打开本次任务 Space。成功后清空编辑内容，保留渠道选择；打开失败则保留原稿。

状态界面与操作结束与重置
待发布正文可编辑，标题和图片选填；主按钮「发布」。空白正文无法启动；不清理或改写用户输入。
正在填写有效点击后进入执行态，窗口隐藏一次；菜单栏显示进度，可随时唤醒。仍有渠道执行时，不提前交还整个任务或重置。
等待登录需登录图标可点击，直达该渠道 Page；大黑主按钮为「我已登录，继续」，点击后逐个检查待登录渠道，已登录的恢复，未登录的保持等待。仅该渠道暂停，任务仍未结束；其他渠道继续。示例中登录按钮可重复体验“仍未登录”。
跳过登录「跳过，手工处理」结束剩余待登录渠道，归入需处理。避免用户不登录时永远卡住；这是本次原型中的建议入口。
全部填好渠道均显示成功对勾，大黑主按钮「已填写，需要你手工发布」。Space 已完成、控制权已交还；点击并打开成功后才恢复新稿。
存在异常「微博、X 需要处理」＋「去查看」；不增加普通异常的恢复流程。部分或全部异常共用此终点；前往当前任务 Space 后恢复新稿。
导航失败轻提示「未能打开本次任务 Space，请再试一次」，保留同一主按钮。不清空、不跳其他 Space、不重新填写。
体验中的模拟边界

「从头体验」会模拟隐藏窗口、逐个渠道填写与登录暂停；其他场景可直接查看状态。渠道网页、Space 状态和控制权只作演示；不会真实登录或发布。登录期间局部开放操作与其他渠道并行的真实能力，需要结合 ego Lite 的控制权粒度验证，不能凭本原型认定已实现。

03 / DESIGN & DEVELOPMENT REFERENCE

界面简单，状态各司其职。

沿用 #47 的纸白、鼠尾草绿和轻量暖色提示；复用现有任务、Space 与渠道 Page 映射。

视觉规范

420 px / 18 px窗口宽 / 内容左右边距
140 px正文高度，约六行；超出内部滚动
42 px / 8 px主按钮高度 / 圆角
轻量状态图标颜色配合形状区分，不用重红色警告框
等宽渠道三列排列，状态由小符号补充
无消散动画仅按钮反馈和执行进度动效，支持减少动态效果

流程约束

登录后继续须复用原任务输入快照、原 Space 与 Page，从可验证位置继续，不重复创建或填写。导航和继续按钮执行中防重复点击；切换任务后旧事件不得修改新稿。所有渠道结束后，无论成功与否都统一收尾。

本页为无外部依赖的 HTML / CSS / JS 原型。复用既有原型的样式和原生浏览器控件，不引入新框架；未改正式应用或其他原型。

职责开发参考
Model渠道执行结果、等待登录、任务终态与导航状态分别建模；可见的两种结果不要求内部所有状态合并。正文保留原样快照。
Controller / Services沿用任务调度与浏览器交还机制；适配器明确报告未登录。继续前复查登录；校验本次任务身份后导航；确认导航成功才重置。
View移除独立登录提示栏。状态图标位于等宽渠道标签右侧；成功用对勾、填写用旋转进度、登录用门与箭头、其他问题用菱形感叹号。登录和问题图标可聚焦、可点击，悬停显示文字说明。大黑主按钮始终保留，负责开始、继续和最终前往。汇总与跳过使用同一字号、行高，居中同排。其他异常只显示渠道名称及一个前往入口。返回新稿时正文获取焦点，已选渠道保留。
验收范围本原型检查四种图标、渠道级页面导航、登录往返、仍未登录、跳过、两类终点、全失败、导航失败保留与成功后重置。正式签名原生应用、真实控制权交还及真实平台输入另行验收。
