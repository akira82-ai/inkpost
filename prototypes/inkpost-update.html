02 / REQUIREMENTS · CAPABILITIES · STATES

一个提醒，两个入口。

已确认 · 点击后才下载

自动检查并提醒，用户点击后下载、安装并重启。不提前自动下载。默认每天检查一次，可在设置关闭。

已实现 · 提醒放标题栏

发现新版后，在齿轮旁显示「有更新」。查看详情展示版本差异、更新说明和「下载并更新」，可选「稍后」。稍后收起面板，入口仍保留。

已实现 · 设置提供常驻入口

设置内提供「软件更新」、当前版本、自动检查开关和手动检查。未发现更新时，主窗口不显示更新入口。手动检查明确反馈最新版或检查失败。

安全保护：有在途任务、待登录渠道、未交接结果或草稿时，先处理内容。下载后再次检查，点击「重启并使用新版」才主动安装重启。未模拟断点续传、真实安装、签名校验或跨重启恢复。
状态显示与操作
发现新版标题栏「有更新」；点开后才展示说明和下载按钮，后台发现不抢焦点。
正在检查 / 最新版设置面板内显示进度与检查结果；背景检查无新版不提示。
用户开始下载显示下载进度和取消；收起面板后标题栏保留进度入口，再打开不重启下载。模拟下载结束后校验，停在准备就绪，等待点击「重启并使用新版」。
任务中 / 还有内容仍可读更新说明，下载更新按钮暂不可用；说明阻止原因。任务完成也不擅自开始安装。
检查 / 下载 / 校验失败给出简短原因，可重试或稍后；不宣称已更新，不改变草稿。
模拟更新完成点击重启后演示版本变为 0.17.0；实际辅助进程替换和单实例启动已通过隔离应用验收，线上分发待发布。
03 / DESIGN · FLOW · DEVELOPMENT

复用系统能力，少造一套界面。

视觉规范

主窗口沿用 420px 宽、纸白 #FCFBF7、墨色 #252923、鼠尾草绿。更新入口 10px 字号，详情面板内边距 21px、主按钮高 42px。错误用轻量文字，不用大红色面板。

交互规范

对话框支持键盘焦点、Escape 收起和焦点返回；收起不取消下载，取消须显式点击。开启动作由用户发起；提醒不抢焦点。支持减少动态效果。

实现边界

复用成熟 macOS 更新器的版本检查、下载、验签和安装能力。已接入 Sparkle 2.10.1，原生自定义面板仅负责展示与用户选择，框架负责下载、验签和独立进程安装重启。

自动检查 → 标题栏提醒 → 用户查看说明 → 确认下载并更新 → 校验通过 → 等待重启确认 → 安全退出与安装 → 单进程启动新版。
当前限制：正式签名为本地 Inkpost 自签名，尚未完成 Developer ID 公证；GitHub 更新源须随首个含 appcast.xml 的 Release 发布后生效。
